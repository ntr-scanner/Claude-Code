Prima di fare qualsiasi cosa nel workspace `Web Developer` leggere `Claude/INDEX.md`. Regole, skill, note e direttive nuove vanno aggiunte o modificate dentro `Claude/`, mai in nuovi file `CLAUDE.md` o di istruzioni altrove. L'unico `CLAUDE.md` è `Web Developer/CLAUDE.md` (solo rimando).

**Why:** l'utente vuole un'unica fonte di riferimento, versionabile su un repo GitHub privato di backup, senza regole sparse in più file.

**How to apply:** per una nuova regola cerca il file giusto in `Claude/` (`INDEX.md`, `SCRIPT.md`, `vektora-wat.md`, `skills/`); skill, agent e memoria attivi sono junction verso `Claude/`: una sola copia, nessuna sincronizzazione. Vedi [[project_vektora]].
